# Template extension for Skybrush Server

[![Copier](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/copier-org/copier/master/img/badge/badge-grayscale-inverted-border-orange.json)](https://github.com/copier-org/copier)

This repository contains a [Copier](https://copier.readthedocs.io/) template for
creating a new extension for [Skybrush Server](https://skybrush.io). It is intended to
be used as a starting point for developing your own extensions.

To create a new extension based on this template, install
[Copier](https://copier.readthedocs.io/) and run the following command:

```bash
copier copy gh:skybrush-io/skybrush-ext-template <your-extension-name>
```

Refer to the files in the `doc/` folder for more information on how to develop
your extension.
